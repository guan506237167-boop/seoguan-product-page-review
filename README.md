## 输入与输出

输入：产品页正文/截图、真实规格材料、目标采购人群和地区；已有询盘问题。

输出：product-review.md：采购缺口表、参数冲突、建议模块与示例文案、资料补充清单。

## 工作步骤

1. 先确定具体产品与页面任务；分类页不能当单品页评判。
2. 沿适用工况→关键参数→规格选型→交付条件→质量证据→联系动作核对资料。
3. 比较页面和产品资料，标缺失、矛盾、表达不清；认证、产能、交期、MOQ仅凭材料写。
4. 给可直接替换的有依据段落与待补字段，按采购阻碍排序。
5. 检查CTA是否与用户任务对应；没有真实测试数据就只写文案和结构建议。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-product-page-review`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
